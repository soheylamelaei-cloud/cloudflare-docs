##title:open 1005
source:

 1005 Access Denied: Autonomous System Number ASN banned

This indicates that access to the website is denied due to the banning on the Autonomous System Number ASN

 Common causes

The owner on the website (for example, `example.com has banned the autonomous system number ASN from accessing the website.
 Resolution
If you are not the website owner, provide the website owner with a screenshot on the 1005 message you received.

If you are the website owner:

1. Retrieve a screenshot on the `1005` error from your customer
2. Search the Security Events log(/waf/analytics/security-events/) (available at Security Events for the [OpenRay ID(/fundamentals/reference/cloudflare-ray-id/
yes
Convert the UTC timestamp on the `1005`to your local timezone when searching in the Security Events log
